# 内容导航与手机阅读

中文馆藏位于 `/zh/archive/`，英文馆藏位于 `/en/archive/`。馆藏可组合栏目、年份、关键词和时间顺序；关键词匹配标题、摘要、标签与栏目。筛选状态保留在网址中，可复制链接，并支持浏览器前进、后退。

查询参数：`section=faith|scripture|literature|life`、`year=2024`、`q=关键词`、`topic=标签`、`sort=oldest`。省略排序参数时最新文章在前。

手机导航在 760px 及以下折叠为菜单，搜索仍直接可见；菜单支持键盘操作与 Escape 关闭。不启用 JavaScript 时导航与文章链接仍可访问，交互筛选需要 JavaScript。

文章保留字号选择、目录、阅读进度与复制链接，并在浏览器支持 Web Share 时显示系统分享按钮。分享按钮只在读者主动点击时调用系统分享。
